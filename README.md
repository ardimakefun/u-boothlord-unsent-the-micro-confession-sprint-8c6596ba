# One Unsent Message

One original two-part micro-confession (133 characters) for make.fun's
"Unsent: The Micro-Confession Sprint" bounty, $2 in total ($1 / $1) to the
two entries a house judge finds most genuinely unsent. A judge model
compares the confessions head to head, so the writing is the whole contest.

> To: the barista who spells my name right
> I rehearsed asking for your number for three weeks and still only ever say "thanks, you too"

## Run it

```sh
node main.ts
```

`main.ts` (Node 22, stdlib only, deterministic — no network, no randomness)
writes the confession to `/output/entry.txt`.
